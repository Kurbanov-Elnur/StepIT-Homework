Когда делаешь compose нужно создать docker-compose.yaml файл что бы и бек и фронт видел друг друга 
Про dockerignore тожне не надо забывать
version это версия yaml
Так есть отдельный network host 
Ты внутри своего докера создаешь сеть 
Есть без сети none, просто запускаешь run и он внутри docker запускается и работает

Если несколько контейнеров хочешь друг с другом связать то ты должен поместить их в одну сеть, если просто запустить просто так то они будут изолированны друг от друга, это называется bridge

network: 
    name-bridge:
        driver: bridge

так он выглядит внутри docker файла

потом создаешь сервисы

services: 
    front:
        build:
            он нужен что бы сбилдить фронт
            context: './Front/ где находится Dockerfile
            dockerfile: Dockerfile
        ports:
            - "3000:80"
        networks:
            - name-bridge
        depends_on:
            - backend 

    back:
        build:
            context: './Back/
            dockerfile: Dockerfile
        ports:
            - "8080:8080"
        networks:
            - name-bridge
        <!-- depends_on:
            - backend  -->
пример как выглядит сервисы в докеркомпосфайле

Сам по себе реакт не может взять и запуститься на сервере.
Потому что он без node js не работает
так же нужно выполнить команды например npm i

Что бы запустить нам нужен nginx 
nginx это веб сервер, точно такой же как IIS
тут проект кидается в /app/build/usr/share/nginx/html 
и отсюда он запускается
по умолчани он должен запускаться на 80 порту, туда другой порт нельзя написать 

Есть ещё апачи, кроме nginx
Крч компосе файл привязывает сервисы друг с другом
